# Results Summary - NFT Spinacia Optimization

## Optimal window (validated across T05, T10, T12)

| Parameter | Optimal range | Notes |
| --- | --- | --- |
| pH | 6.0 - 6.4 | Yield drops sharply above 6.8 (Fe availability) |
| EC | 1.5 - 1.8 mS/cm | Below 1.4 starves N; above 1.9 risks osmotic stress |
| Water temp | 19 - 22 C | >24 C correlates with bolting + DO loss |
| Dissolved O2 | >7.5 mg/L | Root respiration; biggest single yield correlate |
| Photoperiod | 14 - 16 h | 16h best yield but marginal returns in energy |
| PPFD | 330 - 380 umol/m2/s | Canopy saturation near 380 |
| Nitrogen | 175 - 195 ppm | Nitrate toxicity (leaf nitrate accumulation) above ~200 |

## Key findings

- Trial T10 (pH 6.1, EC 1.6, temp 20 C, DO 8.1) produced 45.3 g/plant - top of cohort.
- Dissolved oxygen showed the strongest positive yield correlation; low-DO trials (T08) collapsed regardless of nutrition.
- pH above 6.8 depressed yield more than equivalent EC deviation - Fe/Mn lockout visible as interveinal chlorosis by week 3.
- A 14h photoperiod at 340-370 PPFD was the energy-efficient optimum; pushing to 16h added <4% yield.

## Caveats

- Single cultivar, single season; results transfer to other leafy greens only directionally.
- Sample dataset packaged with this repo is a condensed reconstruction for tooling validation.
